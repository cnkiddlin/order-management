新增订单总览页面 ✓ 已交付
汇总系统全部订单，支持状态筛选、关键词搜索与分页浏览，从导航栏统一入口进入。

完成的功能

  • 订单总览页面 /orders 独立路由 + 模板，展示所有订单的编号、客户、下单时间、状态、金额，可点击订单编号跳转详情。
  • 关键词 + 状态筛选 支持按订单编号/客户姓名搜索，及按「待付款、处理中、已发货、已完成」4 种状态过滤，带重置按钮。
  • 分页控件 默认每页 20 条，显示总条数及当前范围，支持上一页 / 下一页 / 页码直跳，最大 100 条/页可配置。
  • 导航栏更新 两个页面顶栏均增加「订单查询 / 订单总览」导航链接，高亮当前激活页。
  • REST API GET /api/orders 支持 ?q=（关键词）、?status=（状态）、?page=、?page_size= 四个参数，复用现有 load_orders()。
